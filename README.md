# My Portfolio 💻✨

Welcome to my personal portfolio! This website showcases my projects, skills, and experience as a developer. It’s built to highlight modern web development practices while keeping the user experience smooth and interactive.  

---

## About

- Fully responsive and modern design  
- Smooth animations and interactions powered by **Framer Motion**  
- Developed with **React**, **TypeScript**, and **Tailwind CSS**  
- Focused on clean UI/UX and performance  

The portfolio includes sections for my projects, skills, contact information, and more, all designed to provide a clear view of my work and capabilities.  

---

## Features

- Animated transitions between sections  
- Project showcase with live demos and GitHub links  
- Contact form for easy outreach  
- Mobile-friendly and optimized for fast loading  

---

## Tech Stack

- **Frontend:** React + TypeScript  
- **Styling:** Tailwind CSS  
- **Animations:** Framer Motion  
- **Deployment:** Vercel
